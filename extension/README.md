# Браузерное расширение «Китайский тренажёр»

Выделили китайский текст (или русское слово) на любой странице — новости, субтитры,
статья — и одним кликом отправили его в приложение, где оно сразу подставляется
в переводчик на вкладке «Добавить».

## Установка (Chrome / Edge / другой Chromium-браузер)

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите «Режим разработчика» (переключатель в правом верхнем углу).
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`.
4. Откройте настройки расширения (правый клик по иконке → «Параметры», либо
   кнопка «Настроить адрес приложения» в всплывающем окне) и укажите адрес,
   по которому открыто ваше приложение — например, `http://localhost:5173/`
   во время разработки, или адрес вашего хостинга после деплоя.

## Как пользоваться

- **Контекстное меню**: выделите текст на странице → правый клик →
  «Добавить «…» в Китайский тренажёр» → откроется вкладка с приложением,
  слово уже в переводчике.
- **Кнопка расширения**: выделите текст → нажмите на иконку расширения →
  «Добавить выделенный текст».

## Как это работает

Расширение не хранит собственный словарь и не обращается к серверу — оно
просто открывает приложение по адресу `APP_URL#add=<выделенный текст>`.
Основное приложение (см. `src/App.jsx`) при загрузке проверяет хеш `#add=`,
переключается на вкладку «Добавить» → «Переводчик» и сразу запускает перевод
для присланного текста. Вся логика перевода и добавления карточки остаётся
в самом приложении — расширение лишь передаёт текст.

## Ограничения

- Приложение должно быть открыто (или быстро открываемо) по сохранённому
  адресу — расширение не содержит офлайн-словаря само по себе.
- На служебных страницах браузера (`chrome://...`) получить выделение нельзя —
  это ограничение самого браузера.

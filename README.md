# Приложение для изучения китайского языка

Веб-приложение для заучивания иероглифов с интервальным повторением (SRS).

## Стек
- JavaScript
- HTML / CSS
- localStorage

## Структура
- src/ — исходный код
- data/ — список слов
- tests/ — unit-тесты
- docs/ — документация

## Запуск
Открыть src/index.html в браузере.

# Взаимное ревью отладки (день 6)

## Дата: 26.09.2026
## Проверяющие: Широков, Толоконникова

### Комментарий 1
**Файл:** `src/session.js`, функция `answerCard`
**Замечание:** при `quality < 3` карточка сбрасывается, но не добавляется заново в очередь — пользователь не повторит её в этой же сессии. Для учебного приложения это спорно.
**Решение:** добавить карточку в конец очереди при ошибке.

### Комментарий 2
**Файл:** `src/storage.js`, `loadCards`
**Замечание:** при битом JSON возвращается пустой массив без уведомления пользователя. Ошибка глотается.
**Решение:** добавить `console.error` и/или баннер в UI.

### Комментарий 3
**Файл:** `src/app.js`, `renderCardsList`
**Замечание:** используется `innerHTML` с пользовательскими данными (иероглиф, перевод). Потенциальный XSS, если данные придут извне.
**Решение:** использовать `textContent` или экранирование.

### Комментарий 4
**Файл:** `src/srs.js`, `calcNextReview`
**Замечание:** easeFactor округляется до 2 знаков — это ок, но в отчёте об отладке это не упомянуто.
**Решение:** добавить в debug-report.md как проверенный показатель точности.

### Комментарий 5
**Файл:** `docs/debug-report.md`
**Замечание:** ошибки описаны, но нет ссылок на конкретные коммиты — сложно проверить.
**Решение:** добавить хеши коммитов (см. п. 3 ниже).

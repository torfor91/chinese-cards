# Руководство по установке
## Chinese Cards — приложение для изучения китайского языка

**Версия:** 1.0

---

## 1. Требования

- **Браузер:** Chrome 100+, Firefox 100+, Edge 100+.
- **Node.js:** 18+ (только для разработки и тестов).
- **Git:** для клонирования репозитория.
- **VS Code:** рекомендуется, с расширением Live Server.

---

## Найденные ошибки

### Ошибка 1: приложение не загружалось через file://
- **Тип:** интеграции
- **Где:** `src/index.html`, подключение `app.js`
- **Симптом:** пустой экран, в консоли `CORS policy: Cross origin requests are only supported for protocol schemes: http, https`
- **Причина:** ES-модули (`import`/`export`) не работают при открытии через `file://`
- **Решение:** запуск через локальный HTTP-сервер (Live Server / `python -m http.server`)
- **Статус:** исправлено
- **Коммит:** b7ed4fc

### Ошибка 2: дублирование валидации
- **Тип:** логическая
- **Где:** `src/card.js`, `src/validation.js`
- **Симптом:** две функции `validateCard` с разной логикой
- **Причина:** при создании `card.js` скопировали логику из `validation.js`
- **Решение:** `validation.js` реэкспортирует `validateCard` из `card.js`
- **Статус:** исправлено
- **Коммит:** 70048f0

### Ошибка 3: nextReviewDate равен null
- **Тип:** времени выполнения
- **Где:** `src/srs.js`, `isDueForReview`
- **Симптом:** все карточки считались «не готовы» при первом запуске
- **Причина:** `createCard` создаёт карточку с `nextReviewDate: null`, функция не обрабатывала null
- **Решение:** добавлена проверка `if (!card.nextReviewDate) return true`
- **Статус:** исправлено
- **Коммит:** 23bb161

### Ошибка 4: storage возвращал не массив
- **Тип:** интеграции
- **Где:** `src/storage.js`, `loadCards`
- **Симптом:** `stats.js` падал с `cards.filter is not a function`
- **Причина:** после версионирования `loadCards` возвращал объект `{version, cards}`
- **Решение:** `loadCards` возвращает `parsed.cards`, проверка через `Array.isArray`
- **Статус:** исправлено
- **Коммит:** eca088e

### Ошибка 5: отсутствие отладочного режима
- **Тип:** логическая
- **Где:** `src/app.js`
- **Симптом:** при отладке не было логов для проверки состояния
- **Причина:** не был реализован переключатель DEBUG
- **Решение:** добавлена константа `DEBUG = true` с `console.log` и `console.table`
- **Статус:** исправлено
- **Коммит:** 925b47a

## Качественные показатели

### Как проводилась проверка

Все показатели проверялись в браузере Chrome через DevTools (F12) на локальном сервере `http://127.0.0.1:5500/src/index.html`.

### 1. Время загрузки

**Как проверял:** DevTools → вкладка **Network** → обновить страницу (F5) → посмотреть строку `index.html` и все модули (`app.js`, `srs.js`, `card.js`, `storage.js`, `session.js`, `stats.js`) → колонка **Time** / **Load**.

**Требование:** < 2 секунд.

**Факт:** общее время загрузки всех модулей — **0.4 с**.

**Статус:** ✅

### 2. Ошибки в консоли

**Как проверял:** DevTools → вкладка **Console** → пройти полный цикл:
1. Открыть приложение.
2. Добавить карточку.
3. Запустить сессию.
4. Ответить на 3 карточки.
5. Обновить страницу.

**Требование:** 0 ошибок (красных сообщений).

**Факт:** после полного цикла — **0 ошибок**. Есть только информационные `console.log` и `console.table` из DEBUG-режима.

**Статус:** ✅

### 3. Корректность SRS

**Как проверял:** DevTools → **Sources** → точка останова в `src/srs.js` внутри функции `calcNextReview` → запустить сессию → посмотреть значения переменных `interval`, `easeFactor`, `repetitions` в панели **Scope** и **Watch** на каждом шаге.

**Требование:** интервал должен расти при правильных ответах.

**Факт:**

| Ответ | repetitions | interval | easeFactor |
|---|---|---|---|
| 1-й (quality=5) | 1 | 1 | 2.6 |
| 2-й (quality=5) | 2 | 6 | 2.7 |
| 3-й (quality=5) | 3 | 15 | 2.8 |

**Статус:** ✅

### 4. Сохранение данных между сессиями

**Как проверял:**
1. Добавить 3 карточки.
2. Обновить страницу (F5).
3. Проверить, что карточки на месте.
4. DevTools → **Application** → **Local Storage** → `http://127.0.0.1:5500` → ключ `chinese-cards`.

**Требование:** данные сохраняются.

**Факт:** после F5 все карточки на месте, в localStorage лежит массив с корректными полями (`id`, `hieroglyph`, `translation`, `pinyin`, `tone`, `interval`, `easeFactor`, `repetitions`, `nextReviewDate`).

**Статус:** ✅

### 5. Адаптивность (320px)

**Как проверял:** DevTools → **Toggle Device Toolbar** (Ctrl+Shift+M) → выбрать **iPhone SE (375×667)** и вручную выставить ширину **320px** → проверить все три вкладки (Учёба, Карточки, Статистика).

**Требование:** вёрстка не ломается, кнопки доступны, текст читается.

**Факт:** на 320px навигация переносится в столбик, кнопки ответа становятся вертикальными, карточка не обрезается, статистика укладывается в 2 колонки.

**Статус:** ✅

## Найденные ошибки

### Ошибка 1: приложение не загружалось через file://
- **Тип:** интеграции
- **Где:** `src/index.html`, подключение `app.js`
- **Симптом:** пустой экран, в консоли `CORS policy: Cross origin requests are only supported for protocol schemes: http, https`
- **Причина:** ES-модули (`import`/`export`) не работают при открытии через `file://`
- **Решение:** запуск через локальный HTTP-сервер (Live Server / `python -m http.server`)
- **Статус:** исправлено
- **Коммит:** b7ed4fc

### Ошибка 2: дублирование валидации
- **Тип:** логическая
- **Где:** `src/card.js`, `src/validation.js`
- **Симптом:** две функции `validateCard` с разной логикой
- **Причина:** при создании `card.js` скопировали логику из `validation.js`
- **Решение:** `validation.js` реэкспортирует `validateCard` из `card.js`
- **Статус:** исправлено
- **Коммит:** 70048f0

### Ошибка 3: nextReviewDate равен null
- **Тип:** времени выполнения
- **Где:** `src/srs.js`, `isDueForReview`
- **Симптом:** все карточки считались «не готовы» при первом запуске
- **Причина:** `createCard` создаёт карточку с `nextReviewDate: null`, функция не обрабатывала null
- **Решение:** добавлена проверка `if (!card.nextReviewDate) return true`
- **Статус:** исправлено
- **Коммит:** 23bb161

### Ошибка 4: storage возвращал не массив
- **Тип:** интеграции
- **Где:** `src/storage.js`, `loadCards`
- **Симптом:** `stats.js` падал с `cards.filter is not a function`
- **Причина:** после версионирования `loadCards` возвращал объект `{version, cards}`
- **Решение:** `loadCards` возвращает `parsed.cards`, проверка через `Array.isArray`
- **Статус:** исправлено
- **Коммит:** eca088e

### Ошибка 5: отсутствие отладочного режима
- **Тип:** логическая
- **Где:** `src/app.js`
- **Симптом:** при отладке не было логов для проверки состояния
- **Причина:** не был реализован переключатель DEBUG
- **Решение:** добавлена константа `DEBUG = true` с `console.log` и `console.table`
- **Статус:** исправлено
- **Коммит:** 925b47a

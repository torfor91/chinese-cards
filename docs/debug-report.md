## Найденные ошибки

### Ошибка 1: дублирование валидации
- **Тип:** логическая
- **Где:** `card.js`, `validation.js`
- **Симптом:** две функции `validateCard` с разной логикой — при вызове из `app.js` проверялась не та
- **Причина:** при создании `card.js` скопировали логику из `validation.js`, но не удалили дубль
- **Решение:** оставить `validateCard` только в `card.js`, из `validation.js` импортировать
- **Статус:** исправлено
- **Коммит:** (хеш)

### Ошибка 2: nextReviewDate равен null
- **Тип:** времени выполнения
- **Где:** `srs.js`, функция `isDueForReview`
- **Симптом:** при первом запуске сессии все карточки считались «не готовы»
- **Причина:** `createCard` создаёт карточку с `nextReviewDate: null`, а `isDueForReview` не обрабатывал null
- **Решение:** добавлена проверка `if (!card.nextReviewDate) return true`
- **Статус:** исправлено
- **Коммит:** (хеш)

### Ошибка 3: storage возвращает объект вместо массива
- **Тип:** интеграции
- **Где:** `storage.js`, `loadCards`
- **Симптом:** `stats.js` падал с ошибкой `cards.filter is not a function`
- **Причина:** после добавления версионирования `loadCards` возвращал `{ version, cards }`, а не массив
- **Решение:** `loadCards` возвращает `parsed.cards`, проверка через `Array.isArray`
- **Статус:** исправлено
- **Коммит:** (хеш)

### Ошибка 4: события не срабатывают
- **Тип:** интеграции
- **Где:** `app.js`
- **Симптом:** кнопка «Начать сессию» не реагировала на клик
- **Причина:** `addEventListener` вызывался до загрузки DOM
- **Решение:** обернуть инициализацию в `DOMContentLoaded`
- **Статус:** исправлено
- **Коммит:** (хеш)

### Ошибка 5: localStorage перезаписывался
- **Тип:** логическая
- **Где:** `session.js`, `answerCard`
- **Симптом:** после ответа на карточку терялись остальные карточки
- **Причина:** `saveCards` вызывался с одной карточкой вместо всего массива
- **Решение:** загрузить все карточки, заменить нужную, сохранить массив
- **Статус:** исправлено
- **Коммит:** (хеш)

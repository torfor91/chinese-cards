## TC-21: StorageError при переполнении
- **Сценарий:** TS-10
- **Приоритет:** средний
- **Способ воспроизведения (конкретный):**
  1. Открыть консоль (F12) → вставить:
     ```js
     localStorage.removeItem('chinese-cards');
     const cards = [];
     for (let i = 0; i < 5000; i++) {
       cards.push({
         id: 'id' + i, hieroglyph: '好',
         translation: 'хорошо' + 'x'.repeat(900),
         pinyin: 'hǎo', tone: 3, interval: 0,
         easeFactor: 2.5, repetitions: 0, nextReviewDate: null
       });
     }
     localStorage.setItem('chinese-cards', JSON.stringify(cards));

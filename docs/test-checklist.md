# Чек-лист ручного тестирования

## Дата: 30.09.2026
## Команда: Широков, Толоконникова
## Тестировщик: Широков

## Функциональность
- [x] Добавление карточки с валидными данными.
- [x] Валидация пустого иероглифа.
- [x] Валидация пустого перевода.
- [x] Валидация длины иероглифа (границы 10/11).
- [x] Валидация тона (0–4, «не число»).
- [x] Запуск сессии с карточками.
- [x] Показ перевода и ответ.
- [x] Завершение сессии.
- [x] Запуск сессии без карточек.
- [x] Сохранение между сессиями.
- [x] Удаление карточки.
- [x] Статистика прогресса.

## Нефункциональность
- [x] Приложение загружается < 2 секунд.
- [x] Нет ошибок в консоли (при обычной работе).
- [x] Интерфейс работает на экране 320px.
- [x] localStorage не превышает 5 MB.

## Обработка ошибок
- [x] При пустом иероглифе — понятное сообщение.
- [x] При тоне вне диапазона — сообщение об ошибке.
- [x] При битом JSON в localStorage — приложение не падает.
- [x] При переполнении localStorage — плашка StorageError.

## Роли
- **Тестировщик 1 (Широков):** функциональность (карточки, сессия).
- **Тестировщик 2 (Толоконникова):** нефункциональность (скорость, адаптивность, обработка ошибок).

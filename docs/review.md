# Ревью кода (день 4)

## validation.js
1. Функция `validateCard` возвращает объект ошибок или null — удобно для UI.
2. Константы вынесены в UPPER_SNAKE_CASE — соответствует стандартам.
3. JSDoc есть у обеих функций — ок.
4. Проверка тона: `typeof !== 'number'` обрабатывает «не число» — корректно.
5. Пиньинь проверяется только если заполнен — соответствует требованию (необязательное поле).

## srs.js
1. `calcNextReview` корректно сбрасывает repetitions при quality < 3.
2. Ease factor не опускается ниже 1.3 — защита от деградации.
3. Имена переменных понятные, константы в UPPER_SNAKE_CASE.

## storage.js
1. `loadCards` обрабатывает пустой localStorage и битый JSON — не падает.
2. `STORAGE_KEY` вынесен в константу — легко менять.

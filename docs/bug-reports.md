## Реальные дефекты

### BR-01: XSS через innerHTML в renderCardsList
- **Связанный тест-кейс:** TC-01
- **Приоритет:** высокий
- **Тип:** безопасность
- **Шаги воспроизведения:**
  1. Вкладка «Карточки».
  2. Ввести иероглиф `<img src=x onerror=alert(1)>`, перевод «тест», тон 3.
  3. Нажать «Добавить».
- **Ожидаемый результат:** тег отображается как текст (экранирован).
- **Фактический результат (до исправления):** браузер интерпретирует тег, срабатывает `onerror`. **FAIL.**
- **Причина:** `app.js`, `renderCardsList` использовал `innerHTML` без экранирования.
- **Решение:** добавлена функция `escapeHtml()`, все пользовательские данные (`hieroglyph`, `translation`, `pinyin`, `tone`, `id`) прогоняются через неё перед вставкой в `innerHTML`.
- **Повторный прогон TC-01 после исправления:** тег `<img src=x onerror=alert(1)>` отображается как текст, alert не срабатывает. **PASS.**
- **Статус:** закрыт
- **Коммит:** (хеш из шага 1)
- **Исполнитель:** Широков

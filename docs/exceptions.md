# Исключительные ситуации

## Дата: 28.09.2026
## Команда: Широков, Толоконникова

| № | Ситуация | Где возникает | Тип | Способ обработки |
|---|----------|---------------|-----|------------------|
| 1 | Пользователь вводит пустой иероглиф | Форма добавления | Валидация | ValidationError, сообщение в UI |
| 2 | Иероглиф длиннее 10 символов | Форма добавления | Валидация | ValidationError, сообщение в UI |
| 3 | Тон вне диапазона 0–4 | Форма добавления | Валидация | ValidationError, сообщение в UI |
| 4 | localStorage переполнен | Сохранение | Системная | StorageError, предложение очистить старые карточки |
| 5 | localStorage содержит битый JSON | Загрузка | Данные | Fallback: вернуть пустой массив + console.warn |
| 6 | Сессия запущена без карточек | Учёба | Бизнес-логика | SessionError, сообщение «Нет карточек» |
| 7 | Ответ без показа перевода | Учёба | Бизнес-логика | SessionError, кнопки скрыты до показа |
| 8 | Оценка вне диапазона 0–5 | SRS | Валидация | ValidationError |
| 9 | Карточка не найдена по id | Удаление | Данные | Fallback: ничего не делать |
| 10 | Деление на ноль в статистике (total=0) | Статистика | Бизнес-логика | Fallback: вернуть 0% |

## Приоритеты

- **Критические:** 4, 5 — приложение не должно падать.
- **Важные:** 1, 2, 3, 6, 7, 8 — пользователь должен получить понятное сообщение.
- **Желательные:** 9, 10 — graceful degradation.

## Стратегии обработки

- **Fail fast:** 1, 2, 3, 8 — выбрасываем ValidationError, прерываем операцию.
- **Graceful degradation:** 4, 6, 7 — сообщение пользователю, приложение продолжает работу.
- **Fallback:** 5, 9, 10 — возвращаем значение по умолчанию.
